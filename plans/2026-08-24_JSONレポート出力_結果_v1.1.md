# 実施結果 追記: ヘルプ機能のアプリ内組み込み(v1.1)

対象: [結果v1.0](2026-08-24_JSONレポート出力_結果_v1.0.md)の続き。計画書v1.2には含まれていなかった追加対応。

## 経緯

「ヘルプは入れてない？」という質問を受け、`resources/help/help.md`/`help_jp.md`はファイルとしては存在するが、アプリのヘルプメニューから開く導線が未実装だったことが判明。ユーザーから「組み込んで、適切にインデント付けて、各項目と本文の間には空白行入れない、項目間には空白行入れる」と実装指示を受け対応した。

## 実施内容

- `bundle_html.py`: `resources/help/help.md`・`help_jp.md`をビルド時に読み込み、`json.dumps(..., ensure_ascii=False)`でJSON化し、バンドルHTMLの`<script>`冒頭に`window.HELP_MD = {en:..., ja:...};`として埋め込む処理を追加(既存のRCDATA埋め込み経路にそのまま乗るため、ネイティブ側の変更は不要)
- `static/js/app.js`:
  - 外部ライブラリなしの自前Markdownサブセットレンダラー(`mdInline()`/`renderMarkdown()`)を追加。見出し(h1-h4)・段落・強調(`**`)・インラインコード・リンク・箇条書き(順序/非順序)・表に対応
  - 相対パスリンク(`[English help.md](help.md)`等)は`http(s)://`で始まる場合のみ実リンク化し、それ以外はプレーンテキスト化(アプリ内で開けない相対リンクへのナビゲーション事故を防止)
  - `showHelp()`/`hideHelp()`、メニューアクション`help`、i18nキー`act_help`を追加
- `templates/index.html`: ヘルプメニューに「ヘルプ...」項目(`data-action="help"`)を追加、`#help-overlay`/`.help-dialog`/`#help-content`/`#help-close`のモーダルDOMを追加
- `static/css/style.css`: `.help-dialog`を新設。ユーザー指定の間隔ルールを反映
  - 見出し(h2-h4)は`margin: 18px 0 0`で次のセクションとの間隔のみ確保
  - 直後の本文(p/table/ul/ol)は`margin: 4px 0 0`でほぼ密着(空白行を作らない)
  - リスト・表は`padding-left`/セル`padding`で適切にインデント
  - 幅720px・`max-height: 80vh`・`overflow-y: auto`でスクロール可能
- `document/spec_jp.md`: 画面構成・機能一覧にヘルプダイアログの行を追加
- `resources/help/help.md`/`help_jp.md`: メニュー構成の自己言及箇所(「ヘルプ」の中身)を「ヘルプ / バージョン情報」の2項目に修正

## 検証結果

- `node --check static/js/app.js`: 構文エラーなし
- `renderMarkdown()`を実際の`help_jp.md`全文に対してNode上で実行し、生成HTMLのタグ対応(h1/h2/p/ul/ol/li/table/tr/th/td/code/a)がすべて開閉一致することを確認。相対リンク行が`<a>`化されていない(0件)ことも確認
- `build.bat`成功。GUI実行ファイルは3,818,580 bytes(ヘルプ本文埋め込み分で純増)
- 埋め込み結果の検証: `dist/binary/index.html`から`window.HELP_MD`のJSONを実際に`json.loads`で取り出し、`ja`/`en`それぞれの文字数と冒頭文字列が原稿と一致することを確認。EXEバイナリを直接grepし、日本語本文(「うまく起動しない場合」)・英語見出し(`Troubleshooting`)がそのまま埋め込まれていることを確認(初回はJSON側が`ensure_ascii=True`で`\uXXXX`エスケープされていたため見つからず、`ensure_ascii=False`に修正して解消)

### 未検証

- GUI実機での「ヘルプ...」メニュークリック → モーダル表示 → スクロール → 閉じる、という一連の操作は未確認(方針により実機起動なし)
- 間隔指定(見出しと本文が密着、セクション間は空く)の見た目は、CSSのmargin値としては意図通り実装したが、実画面での視認確認はしていない

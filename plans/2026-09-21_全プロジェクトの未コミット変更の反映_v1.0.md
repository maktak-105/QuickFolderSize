# 全プロジェクトの未コミット変更のコミットと push

## ユーザー指示（原文・2026-09-21、QuickFolderSize の同期の作業の途中で追加）
- 「ほかのもコミット＆プッシュして」

## 解釈（確定ではない）
- 「ほかの」は、QuickFolderSize 以外のプロジェクトで、未コミットの変更が残っているもの。作業ディレクトリの全プロジェクトを調べ、変更があるものを、それぞれのリポジトリでコミットして push する。
- 想定される対象: QuickFileCopy、QuickMarkPDF、QuickDiskRescue（私が `.gitignore` に無視規則を戻したもの）と、QuickImageView（ユーザー自身の `.gitignore` の `graphify-out/` 行。これまで「ユーザーの変更なのでコミットしない」としていたが、今回の指示は全ての変更を対象にしていると読む）。
- 判断が要る点:
  - QuickFolderSize は `main` が保護ブランチ（PR 必須）だった。他のプロジェクトにも同じ保護がある可能性があるため、push が拒否されたら、同じく、ブランチと PR 経由で反映する（保護の回避はしない）。
  - 変更は `.gitignore` の追記だけ。コミット前に、追加行に個人情報や秘密の値が無いことを確認する。
  - 各プロジェクトの `origin` との遅れがあれば、先に fast-forward だけで取り込む。衝突する場合は、止めて報告する。

## 実施内容（予定）
1. QuickFolderSize の同期の完了（PR #14 のマージ後、ローカルの `main` を `origin/main` へ追従、作業用ブランチの削除）。
2. 全プロジェクトの状態（変更、遅れ・先行、ブランチ、保護の有無）を確認する。
3. 変更のあるプロジェクトごとに、コミット → push（保護されていれば PR 経由）。
4. 結果を、この計画書に追記する。QuickFolderSize の計画書は PR 経由で反映する。

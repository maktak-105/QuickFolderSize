# テンプレート移行差分の検査と修正 — 実施結果

## 結果

GUI/CLIビルド成功。バンドルを引数なしで実行しbuild/intermediate/index.htmlを生成。About画像の相対パス修正後に警告なし。MCPサーバーへ配布ZIP直下のQuickFolderSize_cli.exe探索先を追加。MCP内JavaScriptをnode --checkで検証。日英説明の重複ビルド手順と旧版リンクを整理。

## 残件

- QuickDiskRescue / QuickFileCopy / QuickFolderSize / QuickImageView / QuickMarkPDF の変更は未コミット。
- GitHub Actions上の実行とReleaseへの公開は、このローカル検証では確認していない。

## Release 手動実行の整合性

手動実行で入力したタグを `actions/checkout` の `ref` に指定し、そのタグのソースからReleaseアセットを作るよう修正。タグpush時はイベントのrefを使う。

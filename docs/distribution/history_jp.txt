QuickFolderSize - 更新履歴
v3.2.0（2026-09-24）
- 管理者権限で実行したとき（MFT高速経路）の不具合を修正: CLI出力・レポートのパスが空になる／断片化した大きいファイルなど約1万件のサイズが0になる／一部が8.3短縮名で表示される。
- OneDriveなどのクラウドフォルダがスキャン結果から丸ごと除外されていた不具合を修正。オンラインのみのファイルはサイズ0として数える。


v3.1.0（2026-09-20）
- フォルダ構成移行後のビルドと配布設定を修正。


v3.0.0 (2026-09-14)
- MCP(Model Context Protocol)サーバー(mcp-server/、任意機能、本パッケージに同梱)を追加。Claude CodeのようなAIエージェントがGUIを開かずHTTP経由でスキャン結果を取得できます。Node.jsと初回の`npm install`が必要。詳細はmcp_readme_jp.txtを参照

v2.1.1 (2026-08-24)
- 既存のMarkdownレポートに加え、JSONレポート出力(ファイル > レポート作成(JSON)...)を追加。CLI版の出力と同じスキーマ
- スキャン結果をJSONで標準出力するCLI版(QuickFolderSize_cli.exe)を追加。スクリプト・AIエージェント向け。管理者権限を要求しないためUACで止まらない(管理者権限で実行した場合のみMFT高速経路を使用)
- バンドル済みUI HTMLをEXEへリソースとして埋め込み。起動時にディスクからindex.htmlを読まなくなった
- 配布パッケージから単体engine_x64.dllを削除(元々EXEからロードされていなかった)
- 管理者権限でのNTFSボリューム直下MFT高速スキャンを追加
- 起動時にUAC確認を表示し、MFT経路を標準で利用するよう変更
- MFTを利用できない場合のWin32スキャン自動フォールバックを追加
- MFT時のJSONをコンパクト化し、絶対パスをJavaScript側で復元

v2.0.1 (2026-08-18)
- ネイティブ C++17 + WebView2 版をリリース（MinGW-w64 / g++）
- ダークなグラスモーフィズム UI（HTML / CSS / バニラ JS）
- 全深度並列スキャン、mtime キャッシュ、ジャンクション除外
- 表示言語の日本語 ⇔ English 切替
- スキャン時間カードに経過秒を表示（0.2 秒ごとに更新）
- 配布ドキュメント: readme.txt（英語）、readme_jp.txt（日本語）、history.txt / history_jp.txt

# QuickFolderSize 操作説明書

Ver. v3.1.0

## 1. 概要

QuickFolderSize は、ローカルのドライブ・フォルダをスキャンして、フォルダ・ファイルごとの使用容量をツリー表示する Windows アプリです。サイズの大きい順にソートし、割合バーで可視化します。結果は Markdown レポートとして書き出せます。

NTFS ドライブ直下は MFT を直接読む高速経路でスキャンするため、通常のフォルダ列挙より高速です。管理者権限が必要です。

## 2. 起動

`QuickFolderSize.exe` をダブルクリックして起動します。起動時に UAC(ユーザーアカウント制御)の確認画面が表示されるので、「はい」を選んでください。「いいえ」を選んだ場合、アプリは起動せずに終了します。

管理者権限が必要な理由は、NTFS ボリューム直下を `$MFT` から直接読む高速スキャン経路のためです。このアプリは常に管理者権限で起動する前提になっており、管理者権限を許可しない限りメイン画面自体が開きません。

なお、管理者権限で起動できた場合でも、スキャン対象が NTFS ボリューム直下(`C:\` など)でないとき(個別フォルダ、非NTFSドライブ、ネットワークパスなど)は、その対象については通常のフォルダ列挙方式(`FindFirstFileW`)が自動的に使われます。これは UAC の可否とは別の、対象パスの種類による切り替えです。

## 3. 画面構成

| エリア | 内容 |
|:-------|:-----|
| メニューバー | 「ファイル」(開く / 再スキャン / レポート作成 / 終了)、「ヘルプ」(ヘルプ / バージョン情報) |
| 言語切替ボタン | メニューバー右端。クリックで 日本語 ⇔ English を切替(アプリ再起動で日本語に戻ります) |
| アドレスバー | 左端にドライブの使用容量 / 総容量、中央にパス入力欄、右端に「スキャン」ボタン |
| 左ナビペイン | ドライブ一覧とフォルダツリー(クリックで展開) |
| スキャン時間カード | 左ナビ下。スキャン開始からの経過秒を表示し、完了後は固定されます |
| 右スキャンツリー | スキャン結果の階層表示。名前・サイズ・割合バー・ファイル数・更新日時の列を持ちます |

## 4. フォルダをスキャンする

スキャンを開始する方法は 3 通りあります。

1. アドレスバーにフルパスを直接入力し、「スキャン」ボタンを押すか `Enter` キーを押す
2. メニュー「ファイル > 開く...」(`Ctrl+O`)でフォルダ選択ダイアログから選ぶ
3. 左ナビペインのドライブまたはフォルダをクリックする

スキャン開始と同時に、対象フォルダの直下1階層がまず表示されます(サイズは空欄)。スキャンが進むにつれてサイズが埋まっていき、完了するとツリー全体が確定します。

すでにスキャン済みのツリー内にあるフォルダを左ナビでクリックした場合は、再スキャンせずに保持している結果をそのまま表示します。改めて集計し直したいときは、「スキャン」ボタン・メニュー「ファイル > 再スキャン」・`F5`のいずれかで再スキャンしてください(いずれも同じ処理で、アドレスバーの現在のパスを対象にスキャンし直します)。

## 5. スキャン結果の見かた

| 列 | 内容 |
|:---|:-----|
| 名前 | 📁 フォルダ / 📄 ファイル。行クリックでアドレスバーにそのパスが入ります |
| サイズ | フォルダは配下の合計サイズ |
| 割合バー | 親フォルダに対する使用割合を可視化したバー |
| ファイル数 | フォルダ配下の再帰ファイル数 |
| 更新日時 | 最終更新日時 |

- 列見出しをクリックすると、その列で昇順 / 降順にソートできます(初期状態はサイズの降順)。
- フォルダ名の左にある ▶ / ▼ をクリックすると展開・折りたたみができます。
- アクセスできないフォルダ(権限不足など)は赤字で表示され、そのフォルダはスキップされます。アプリが異常終了することはありません。
- ジャンクションやシンボリックリンクなどのリパースポイントは、無限ループを避けるため集計対象から除外されます。

## 6. 再スキャンとキャッシュ

一度スキャンしたフォルダを再スキャン(「スキャン」ボタン・メニュー「ファイル > 再スキャン」・`F5`のいずれか)すると、前回から更新日時が変わっていないフォルダは列挙処理を省略し、キャッシュを再利用します。変更があったフォルダだけを実際に読み直すため、2回目以降のスキャンは高速になります。

## 7. レポートを作成する

メニュー「ファイル」には2種類のレポート作成があります。どちらも現在表示中のスキャン結果が対象で、保存先はダイアログで選択します。

- **レポート作成...**(`Ctrl+Shift+S`): 人が読むためのMarkdownファイル。パス・スキャン日時・合計サイズ・サブフォルダ数・ファイル数と、サイズ降順のフォルダ構成一覧が含まれます。
- **レポート作成(JSON)...**: 他ツール・スクリプト・AIエージェントでの機械的な読み込み向けのJSONファイル。内容はMarkdown版と同じ情報を構造化したものです。

どちらもスキャンが完了している場合のみ実行できます(未完了の間はメニュー項目が無効表示になります)。

## 8. 表示言語の切替

メニューバー右端のボタン(🌐)をクリックすると、日本語 / English をその場で切り替えられます。メニュー・列見出し・ボタン・バージョン情報・Markdown レポートの文言すべてに反映されます。この切替はアプリ内だけで完結し、次回起動時は日本語表示に戻ります。

## 9. キーボードショートカット

| ショートカット | 機能 |
|:--------------|:-----|
| `Ctrl+O` | フォルダを開く(選択ダイアログ) |
| `F5` | 再スキャン |
| `Ctrl+Shift+S` | レポート作成(Markdown 保存) |
| `Ctrl+Q` | アプリ終了 |
| `Enter` | アドレスバーにフォーカスがあるときスキャン開始 |

## 10. バージョン情報

メニュー「ヘルプ > バージョン情報...」から、バージョン番号・開発環境・制作者情報を確認できます。

## 11. うまく起動しない場合

- ウィンドウが表示されない場合は、Microsoft Edge WebView2 Runtime がインストールされているか確認してください。
- `QuickFolderSize.exe` は、`WebView2Loader.dll` と同じフォルダに置いてください。離れた場所に置くと起動できません(UIはEXEに埋め込み済みのため、`index.html`は不要です)。
- それでも起動しない場合は、EXE と同じフォルダに出力される `QuickFolderSize_debug.log` を確認してください。
- UAC 確認画面で「いいえ」を選んだ場合、アプリは起動しません。再度起動して「はい」を選んでください。
